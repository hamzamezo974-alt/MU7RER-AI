# MU7RER-AI | المُحَرِّر لتحقيق النصوص والمخطوطات

منصة عربية متكاملة لتحقيق النصوص والمخطوطات بالذكاء الاصطناعي المدمج، تضم محركاً صرفياً ونحوياً، وكاشفاً للتصحيف والتحريف على الرسم الخطي، ومحرك مقابلة نقدية آلية، وتجزئة بصرية لصفحات المخطوطات، وتصدير قياسي بصيغ Word وTEI-XML وXeLaTeX.

## المحركات المدمجة (`src/lib/manuscript-core`)
- **محرك الصرف والإعراب (`morphology.ts`):** تجريد السوابق واللواحق، استنباط الجذور والأوزان القياسية، والتشكيل الآلي السياقي.
- **مفسر الرسم الخطي وكاشف التصحيف (`script-normalizer.ts`):** مطابقة الهيكل غير المنقوط (Rasm Skeleton) وضبط الهمزات والرسم التراثي.
- **محرك المقابلة النقدية (`critical-collation.ts`):** محاذاة تسلسلية للنسخ وتوليد حواشي الفروق النقدية آلياً.
- **محرك الرؤية الحاسوبية وتجزئة الصفحات (`layout-segmenter.ts`):** خوارزمية Sauvola لعزل الحبر عن الرق وفصل المتن عن الحواشي والتعقيبة.
- **محرك التخريج والفهارس (`takhrij-engine.ts`):** تخريج الآيات والأحاديث وتراجم الأعلام واستخراج الكشافات العلمية.
